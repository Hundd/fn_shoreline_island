Use existing shooting_gallery for the bay and corridor for arrival; no new pattern/schema. Knowledge is a short board/HUD overlay in the same bay; reward uses retained debug_progress rather than misusing reward_room's Prompt manager contract. Do not declare target_sequence: its fixed Prompt sequence [0,3,5,5,6] is incompatible. No multiplayer controller, extra weapon granter or new generic framework.

After approval refactor the existing debug_station class into one solo controller. Keep the reusable direction fixture behavior; add small editable stage records (start_tile, goal_tile, commands array, editable_slot), three target references, entry volume, five tile anchors, goal/Pix props, boards/HUD, progress lights and Replay/Return. Stage data is the exact spec table; this is a required scoped adapter change, not a claim that arbitrary YAML already configures Verse. Update all placed actor references in the same implementation. Four old placed controllers are retired and one configured instance serves the bay. Keep historical Verse source files that remain unplaced when useful for recovery; do not fabricate retirement by just hiding controls.

Execution: idle -> demonstrate_fault -> choosing -> rerun -> mismatch/verified -> next demonstration or finish. Demonstrate faults once each round. Before and current result, start/goal and boxed plan persist. Each shot edits only that slot, computes and animates every command from the start, then verifies actual endpoint == goal. Never award directly on target ID. If data/refs are invalid fail closed with choices disabled and a diagnostic. generation tokens and active-player checks protect every delayed animation/result; round generation follows retained progress. During locks keep hit observation active so quiet rearm can detect held fire. Debounce mistakes to distinct attempts, not every bullet in a burst. Return cancels first, then teleports; walking departure does the same cancellation. Replay is enabled at finish, preserving completed flags and badge; physical run progress resets independently.
