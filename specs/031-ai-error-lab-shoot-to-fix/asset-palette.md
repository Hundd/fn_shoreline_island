# Functional palette

Reuse the first-floor teaching area and project-owned safe primitives, existing matte Academy/Campus materials and DataBlaster ring/feedback assets. No external art, restricted cat model, industrial prop quota or asset import is required.

| Object | Role and envelope |
|---|---|
| Correction targets | Three 1.5 m faces with permanent LEFT/STOP/RIGHT text and arrow/square symbols; cyan selectable rings. |
| Pix | One eligible existing marker/primitive assembly <=0.9 m wide; readable robot face if feasible with existing primitives; no target ring or collision in shooting lanes. |
| Track | Five numbered tile panels, 2 m center spacing, at raised display height 3 m, above the target faces; numbers/text remain readable and movement endpoints are unambiguous. |
| Goal | Small labelled flag/check marker above the goal tile; goal number persists on the evidence board. Reposition only between rounds. |
| Board | Existing billboard presentation, maximum five concise lines; long hints copied to HUD. Low-glare backdrop if needed. |
| Progress | Three practical light indicators with numeric 0/3..3/3 text; audio is optional reinforcement. |
| Surroundings | Retained useful shelter, necessary edge rails, at most two practical lamps; remove obsolete lab console clutter after dependency audit. |

Glyph support, face coverage, exact native settings and normal player camera readability require implementation/cooked checks. If an existing material fails eligibility, choose an already verified same-role matte project asset within these envelopes; material substitution cannot change target meanings, scale or flow.
