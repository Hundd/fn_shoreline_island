# Repair Button Interaction Labels

## Requirements

- R1: Every repair button must show a concise, player-facing interaction label.
- R2: Labels must state the control's purpose: CLAIM, SLOT 1–4, RUN, HELP, REPLAY, or RETURN.
- R3: Existing button transforms, gameplay bindings, and billboard labels must remain unchanged.

## Acceptance scenarios

### S1: Clear control intent

Given a player looks at any repair control button,
when its interaction prompt appears,
then the prompt names the button's action or slot.
