Twelve target assemblies total. Surface-scan and independent-probe choice positions are neutral: no pre-answer correct-color cue. For scan wrong choices, say “Looks do not measure heat. Choose a temperature test.” Copy feedback: “Same report, not a new measurement.” Likes feedback: “Popularity does not test this core.” SEND feedback: “The inside is hot. A confident prediction can still be wrong.” SKIP feedback: “Release needs checked results.” Final recap: “Useful test. Independent evidence. Check before acting.” The 90% prediction appears at independent check, clearly attributed to Pix; never display a manufactured percentage increase per hit.

Shooting decisions stay static except the coolant control. Reuse synchronized MoveTo for valve prop plus damage surface; maintain labels/rings and stop both together. Wrong hits debounce 0.5 s and leave current state intact. Commit the phase synchronously before async motion; disable/park old surfaces. Require at least 1.2 s feedback and a quiet-hit/rearm interval before activating the next choice group; explicitly test held automatic fire. Pause Motion cancels current motion generation, freezes current transforms and resumes from saved transforms; it never changes which answer is correct. For completed accepted transitions in reduced-motion mode, show result for the same minimum interval then snap to the named endpoint. Repeat Result replays the last reading in HUD without resampling or awarding. Help gives a concept hint, then a worked example on second press.

## Ownership, progress and reset

Start enrolls players within the mission bounds during a five-second window; use explicit Join interaction to avoid enrolling passersby. Start presser is enrolled; peers press the same Start/Join during the window. One run is shared by up to the island's four players. Late arrivals get a spectator notice and cannot trigger targets. Every hit checks agent, membership, current bay, phase and generation. Departure from mission bounds, return, elimination/respawn or disconnect revokes membership. If none remain, cancel and restore home poses. No timeout while an enrolled player is still working.

Keep each participant's completed sections as run-local flags; write all three energy_progress challenge indices through complete only after final release and continuous participation. This avoids stale partial badges from an aborted run. Preserve existing badge guard and round generation. Already earned badges survive replay; replay offers the entire lesson. Replay reopens enrollment at the entry and teleports willing replay participants there via a dedicated local destination, while other players can Return. Round reset clears manager state. Cancel every suspended scanner, valve, lift, core, label and effect callback using a generation token before restoring all home transforms, readings and target states.
