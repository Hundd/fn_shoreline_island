# Restore Repair Button Mounts

## Requirements

- R1: Restore each repair button mount to its pre-clearance relative position.
- R2: Preserve all repaired button player-facing transforms.

## Acceptance scenarios

### S1: Restored support placement

Given the repair supports were moved too far behind the buttons,
when the restoration is applied,
then every mount returns to relative Y=-500 and every button remains player-facing.
